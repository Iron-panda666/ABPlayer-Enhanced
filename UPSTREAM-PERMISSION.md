# Upstream distribution permission

Original application: **ABPlayer by Jose Hidalgo (jhidalgo_dev / kurohige)**.

Enhanced maintainer: **Jiří Veselý, aka Iron-panda666**.

The maintainer asked for permission to distribute a modified Windows installer while retaining the original author's credits and identifying the release as an unofficial modified version.

In [issue #2](https://github.com/kurohige/ABPlayer/issues/2), the repository owner **kurohige** replied:

> Uff that mini player looks legit, I'll copy that design if you don't mind and add it to the version I'm working on. And yes, use the code/player as  you see fit as long as we keep the desktop version open for everyone to use I think is fine :) Best of luck man!

[Direct link to the author's permission](https://github.com/kurohige/ABPlayer/issues/2#issuecomment-7173942970).

The Enhanced maintainer subsequently confirmed that the desktop version would remain free and available to everyone and would retain the original author's credits. The maintainer also invited the original author to integrate useful changes from the fork.

[Direct link to that acknowledgement](https://github.com/kurohige/ABPlayer/issues/2#issuecomment-7175971599).

This record was checked on **26 November 2026**. It preserves the written permission; it does not claim that the upstream author adopted a standard open-source license.
