# ABPlayer 1.7.0-Enhanced.1

First public Windows binary release of the Enhanced fork, shared with the [original author's permission](https://github.com/kurohige/ABPlayer/issues/2#issuecomment-7173942970).

**New naming introduced by Jiří Veselý (Iron-panda666):** `<upstream version>-Enhanced.<revision>` keeps the original base separate from our improvements. This release uses original **ABPlayer 1.7.0** plus **Enhanced revision 1**, including the previous local Enhanced/Fork milestones through 1.7.7. It is not a downgrade. Its GitHub tag is **v1.7.0-enhanced.1**. Windows internally uses build **1.8.0** to preserve forward upgrade ordering. See [version naming](../VERSIONING.md).

## Download

- **Windows x64 setup EXE**: recommended for installing or updating an existing Enhanced/Fork installation. Setup displays the copyright/distribution notice and installs the accompanying notices.
- **Setup ZIP**: the same installer with license texts, credits, permission record and release notes beside it.
- **Portable ZIP**: extract the whole archive into a folder, then run `ABPlayer-Enhanced.exe`. Keep `WebView2Loader.dll`, the notices and the licenses directory with it.
- **SHA256SUMS.txt**: checksums for all three downloads.

The portable ZIP is installation-free; it uses the same per-user Enhanced profile. It is not a separate isolated listening profile. Keep audiobook audio files separately.

## Included improvements over original ABPlayer

- Previous/next chapter and track controls in the main player, Continue card and mini player.
- Bookmarks shown within their matching chapter/track, plus undo seek.
- Tray controls, configurable close behavior, mini player and background opacity.
- Expanded player and multiple live audio visualization styles.
- Configurable sortable library columns, **Unfinished** and exact **0% progress** filters.
- Open Library metadata search by title, author or ISBN; protected editing drafts; separate original-book and audiobook years; exact duration entry.
- Optional Stream Deck hotkeys for playback, volume, mute and bookmarks.
- Full profile backup/restore with folder remapping, installer maintenance, and verified automatic backups before updates and repairs. Keep the newest **3 automatic backups**; manual archives are preserved.

## Changes in 1.7.0-Enhanced.1

- Package the upstream distribution permission, original copyright notice, contributor credits and third-party license texts with both distribution formats.
- Show original and Enhanced authorship in **Settings → About**. Derive the displayed release from release-info.json, replacing the stale hardcoded version.
- Include license information in the installer and preserve the existing profile/installation identities for upgrades.
