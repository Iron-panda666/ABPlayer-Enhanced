# ABPlayer Enhanced 1.7.4

## Book editing fixes

- Year read and publish year use four-digit text entry without numeric spinners starting at year 1. Incomplete or invalid years keep the editor open with a correction message.
- Original book publication year and audiobook release year are separate fields, details and sortable library columns. Existing publication years remain in the original book field; no audio release year is guessed. Open Library's first-publication value only fills the book year.
- Outside clicks, Escape and Cancel cannot silently discard a changed book form. Save, keep editing, or explicitly discard the draft. Reset to original requires confirmation.
- Cover selection stays in the draft until Save, including when editing an existing book.
- Length accepts H:MM:SS, H:MM, decimal hours with a dot, or decimal hours with a comma. Exact seconds are preserved when the dialog opens.
- Length is saved on both new logged books and subsequent edits. Local audiobooks can have a catalog length override; library display and sorting use it, while audio duration, chapter times and listening positions remain unchanged. Clear the field to use the audio length again.
- Pending tags and quotes are included when saving, even if Enter has not been pressed.
- User metadata is flushed to disk before the editor closes; a write failure keeps the draft visible.

## Metadata without ISBN

Open Library lookup now has separate title and author fields. ISBN is optional; either title or author can be searched on its own. Imported fields remain editable in the draft until Save. Results can describe print editions, so the narrator, audiobook release year and audio length still require verification against the audio edition.

No additional API keys or account credentials are required by this lookup. No personal library data is included in source code or installation files.
