# ABPlayer Enhanced 1.7.5

- Added **Unfinished** next to **All** in the Library filters.
- Unfinished excludes only the exact stored status `finished`. Reading, new, unset and unexpected statuses are included. It is not a whitelist of Reading and New.
- The selected filter is remembered between launches and combines with the existing library search, collection and tier filters.
- Books with an unexpected status show a neutral **Unknown** badge instead of causing the list row to fail rendering.

Updates preserve the existing Fork library, listening progress, bookmarks and settings. Close the application normally before running the installer. No user profile data is included in the build.

Binary distribution remains subject to upstream permission. Based on ABPlayer by jhidalgo_dev; original copyright and third-party notices remain applicable.
