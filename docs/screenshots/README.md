# Screenshot provenance

These images were captured directly from a running Windows build of ABPlayer Fork 1.7.3 on 19 November 2026. The screenshot build uses the same source and a separate application identifier to keep its demonstration profile independent of the user's listening profile.

The sample title, author, bookmarks and audio are demonstration material. The sample speech is rendered locally with Windows speech synthesis.

The demonstration cover is an existing National Park Service photograph of Cape Hatteras Lighthouse, marked public domain by its source.
